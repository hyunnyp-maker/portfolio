# Portfolio · 박서현

브랜드 마케팅 · 디자인 · 이커머스 운영 포트폴리오

**🔗 https://hyunnyp-maker.github.io/portfolio**

---

## 개요

(주)파슨스앤코에서 13년간 진행한 브랜드 마케팅 · 디자인 · 이커머스 실무를 정리한 포트폴리오입니다.
자기소개서와 프로젝트 아카이브를 한 페이지에 담았습니다.

- 자체 브랜드 11개 운영 (세컨 8 · 개별 3)
- 신규 브랜드 0→1 런칭 3건 (COLOR BY NUMBER, SAVE A DOG 등)
- 제품 상세페이지 42배치 · 980+ 상품 제작
- 글로벌 마켓 진출 (Etsy · Amazon) · USPTO 상표 출원
- 자사몰 매출 +41% 성장 (2017→2019)
- 드라마·유튜브 협찬(PPL) 12편+ · 롯데백화점 정기 성과 리포팅 (2019–2022)

## 이 페이지에 대하여

템플릿이나 외주 없이 **Claude Code로 직접 설계하고 개발**했습니다.
프레임워크나 빌드 도구 없이 순수 HTML · CSS · JavaScript로 구현했습니다.

**주요 기능**

| 기능 | 설명 |
|---|---|
| 다크 / 라이트 모드 | OS 설정 자동 감지 · 수동 전환 · 선택값 저장 (단축키 `D`) |
| 편집 모드 | 텍스트를 클릭해 바로 수정, 이미지를 클릭해 교체 |
| 저장 | 수정한 내용을 HTML 파일로 즉시 다운로드 |
| 라이트박스 | 이미지 클릭 시 전체화면 확대 |
| 반응형 | 데스크톱 · 태블릿 · 모바일 대응 |
| 스크롤 인터랙션 | 섹션 진입 시 페이드인, 탭 자동 동기화 |

## 구조

```
portfolio/
├── index.html      # 페이지 전체 (마크업 · 스타일 · 스크립트)
└── images/         # 프로젝트 이미지 35개
```

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 그대로 동작합니다.
